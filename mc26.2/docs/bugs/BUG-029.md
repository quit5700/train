# BUG-029：手动卸货和车辆段取车依赖错误触发路径

## 问题类型
服务端核心逻辑 / 容器问题

## 1. 问题现象
独立货车在开启手动卸货的站点不卸货；车辆段不会主动把相邻容器中的车辆物品吸入自身库存。

## 2. 根本原因
手动卸货最初只在线路车头按节点到站时调用，独立货车永远不会进入该路径；第一次修复又增加了速度门槛和“本次到站已处理”锁，即使因容器容量或实体抖动移动 0 件物品，也不再重试。

## 3. 修改文件
- `StationManualUnloadService.java`
- `CargoTransferService.java`
- `DepotDispatchService.java`
- `VehicleAbsorptionRules.java`
- `VehicleAbsorptionRulesTest.java`

## 4. 修复方式
服务器每 Tick（游戏刻）检测站点中心周围的货车，不再要求速度为零，也不设置一次性到站锁；只搬运站点相邻容器中已经存在的同类物品，并在当前 Tick 内按容器剩余容量瞬间完成。车辆段吸取仍由独立周期服务处理。

## 5. 验证方式
匹配物品、非匹配物品和容量不足三项针对性回归均通过，回归探针返回 `MANUAL_REGRESSION_OK`。仍需在游戏内验证货车进入站点范围时瞬间卸货。

## 6. 下次避免
玩家可手动推动的实体功能不能依赖自动线路控制器；可重试的库存操作不得在移动 0 件物品时提前设置永久到站锁。
