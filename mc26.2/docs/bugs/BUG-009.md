# BUG-009：Minecraft 26.2 配方 JSON 格式变化

## 问题现象

专用服务器能够启动，但数据包加载时八个配方全部解析失败。

## 根本原因

配方沿用了旧格式：材料键使用 `{ "item": "..." }`，结果使用 `item` 字段，并填写了 26.2 已不接受的旧分类值。Minecraft 26.2（我的世界 26.2）原版配方改为材料直接写物品标识字符串，结果字段使用 `id`。

## 修改文件

- `src/main/resources/data/fabric_train_simulator/recipe/*.json`
- 本 BUG 记录与索引

## 具体修复方式

参照 Minecraft 26.2 原版 `powered_rail.json`（动力铁轨配方）和 `chest_minecart.json`（运输矿车配方），删除不必要分类，材料改为字符串，结果改为 `id`。

## 如何验证

重新启动专用服务器，确认八个配方不再出现解析错误，并检查加载配方数量。

## 下次应避免

新 Minecraft 版本的资源 JSON（JavaScript 对象表示法）必须用同版本原版数据文件作基准，不能直接沿用旧版本格式。
