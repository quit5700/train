# BUG-018：线路设置器在空存档中没有窗口

## 问题现象

世界还没有线路时，手持铁路线路设置器右击只显示“没有线路”消息，不打开任何设置界面。

## 根本原因

旧入口只能打开已存在的单条线路界面，把“线路为空”当成了终止条件。

## 修改了哪些文件

- `LineSetterItem.java`
- `RailwayManagerNetworking.java`
- `RailwayManagerScreen.java`
- 客户端与服务端初始化和八种语言资源

## 具体修复方式

无论是否存在线路，右击设置器都由服务端发送设备和线路摘要，打开设备/线路两栏管理界面。空状态明确显示创建指引。

## 如何验证

编译客户端和服务端网络 Payload（载荷），运行全部测试并启动客户端检查界面注册。

## 下次应避免

管理工具的主入口必须支持空数据状态，不能依赖“已有一条数据”才能打开。
