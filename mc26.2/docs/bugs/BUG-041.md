# BUG-041：Minecraft 26.2 不识别连接器配方中的 chain 物品键

## 问题类型

版本适配问题 / Recipe（配方）资源问题

## 问题现象

排查车辆段问题时，实际客户端日志另行出现连接器配方解析错误：当前 Minecraft 26.2
（我的世界 26.2）物品注册表不识别 `minecraft:chain`，因此该配方没有加载。

## 根本原因

现有 `train_connector.json`沿用了旧版材料键，未按 26.2 当前物品注册表适配。

## 当前处理状态

本轮用户只授权修复车辆段设置入口和立即发车，因此没有顺便修改配方，避免扩大修改范围；
问题已单独登记，后续处理时应先确认 26.2 的等价原版材料键或由用户决定替代材料。

## 相关文件

- `src/main/resources/data/fabric_train_simulator/recipe/train_connector.json`
- 游戏 `logs/latest.log`

## 验证依据

日志明确记录 `Unknown registry key ... minecraft:chain`。本次 0.2.6 构建不把该独立问题标为已修复。

## 下次避免

版本迁移时不仅要验证 Java（爪哇）接口，还必须在真实客户端资源重载日志中检查每个配方材料键。
