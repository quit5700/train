# BUG-013：列车回收后运行计数未注销

## 问题现象

列车已安全回收为车辆物品，但线路的活动列车表仍保留该列车，可阻止后续发车。

## 根本原因

`discard`（丢弃实体）不属于破坏移除，车头原有的破坏回调不会注销计数。

## 修改了哪些文件

- `DepotRecoveryService.java`
- BUG 记录与索引

## 具体修复方式

回收事务在物品全部成功写入车辆段后，先从服务端存档注销列车唯一编号，再移除实体。

## 如何验证已经修好

重新编译、执行存档回归测试，并启动专用服务端。

## 下次应避免

不要假设所有实体移除原因都会走破坏回调；事务状态应由回收服务显式收尾。
