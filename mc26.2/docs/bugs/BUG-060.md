# BUG-060：列车经过第二站后原路倒退

- 类型：核心逻辑 / 线路验证 / 三维寻路
- 状态：`0.2.25` 已修复代码，待游戏验收

## 1. 问题现象

线路实际铁轨完整，但自动列车到达第二个车站后会原路退回，而不是沿当前驶入方向继续前进。

## 2. 根本原因

`WorldLineValidator（世界线路验证器）`把每两个节点分别扫描，但没有把上一段最后的驶入铁轨传给下一段。`TrackPathScanner（铁轨路径扫描器）`又只以“当前铁轨”作为状态，所以 Breadth-First Search（广度优先搜索）会把刚才的来路当作下一段的最短路。

## 3. 修改文件

- `TrackPathScanner.java`
- `WorldLineValidator.java`
- `TrackPathScannerTest.java`
- `WorldLineValidatorContractTest.java`

## 4. 修复方式

寻路状态改为“上一格铁轨 + 当前铁轨”；扫描新节点段时携带上一段的倒数第二格铁轨，禁止立即返回来路。允许同一道岔从另一驶入方向重新参与搜索，不破坏真实循环线路。

## 5. 验证

`TrackPathScannerTest` 覆盖两车站、立即掉头禁止、同道岔不同来向、循环和三维坡道；`WorldLineValidatorContractTest` 确认线路验证使用有向状态并继承驶入铁轨。

## 6. 下次避免

多节点轨道不得将各段当作完全独立的无向图搜索；任何路径缓存重建都必须保留跨节点驶入方向。
