# BUG-065：车辆模型方向、车辆段即时操作保存与诊断信息残留

## 问题现象

- 隐藏原版矿车外壳后，三个模型与铁轨方向相差 90°，窗户、灯和金边细节不可见。
- “立即生成”和“立即发车”使用窗口临时参数，却未先保存车辆段状态。
- 驾驶、连接和运动过程仍向玩家显示开发阶段诊断信息。

## 根本原因

- 原版 MinecartRenderer（矿车渲染器）会额外旋转显示方块 90°，模型仍按普通方块坐标制作。
- 非 SAVE（保存）动作绕过了车辆段持久化分支。
- 三处诊断发送代码在功能稳定后未清理。

## 修复

- 将三种车辆的全部几何和面方向旋转 90°，长轴仍严格限制在 16 个模型单位内；保留客车和车头的玻璃窗、灯、金边与机械细节，货车保持黑色金边。
- 即时操作先统一保存车辆段名称、线路、编组、车型、速度、间隔和上限，再生成车辆。
- 移除玩家可见的输入、运动和连接距离诊断，保留正常操作结果与错误提示。
