# BUG-058：自动列车在未加载区块无法按预计时间运行与卸货

- 类型：数据保存 / 离线逻辑运行 / 货运
- 状态：`0.2.24` 已实现，待游戏验收

## 1. 问题现象

自动列车在未加载区块只能冻结；玩家提前到目的站无法看到列车按预计时间到达，货车也不能在未加载车站按到站时间卸货。

## 2. 根本原因

原实现只有实体列车，没有持久化 Offline Train（离线列车）状态；旧货运托管按直线距离提前清空货物，也没有使用线路三维路径进度。

## 3. 修改文件

`OfflineTrainState`、`OfflineCarState`、`OfflineTrainSavedData`、`OfflineTrainService`、`OfflineRouteMath`、`TrainControllerManager`、`CargoLedgerService` 和 `FabricTrainMod`。

## 4. 修复方式

只有车辆段生成的自动列车在新区块未加载时转为持久化逻辑状态；保存路径索引、段内进度、速度、下一节点、停靠时间和货物。逻辑列车按真实三维线路距离推进，进入已加载区域后在计算位置恢复实体。到达未加载车站时才把应卸货物写入持久货运账本，车站加载后送入容器。手动列车继续冻结。

## 5. 验证

`OfflineRouteMathTest` 和完整 `gradlew.bat test` 已通过；仍需游戏内跨区块、跨重启和容器容量人工验收。

服务器重启时，持久化离线列车先把火车头、车厢和货物回收到线路回收车辆段；车辆段区块尚未加载时保持待回收，加载后先回收再允许定时重新发车。

## 6. 后续避免

不得按车头到车站的直线距离估算线路到达时间，也不得在尚未到站时提前移除车厢货物。
