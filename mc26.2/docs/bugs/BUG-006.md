# BUG-006：当前构建未拆分独立客户端编译任务

## 问题现象

执行 `compileClientJava`（编译客户端 Java）时，Gradle（构建工具）报告该任务不存在。

## 根本原因

本项目当前未启用 Loom（Fabric 构建插件）的客户端与服务端源码拆分；`src/client/java` 已合并进主源码集，由 `compileJava` 统一编译。

## 修改文件

- `docs/bugs/BUG_INDEX.md`
- `docs/bugs/BUG-006.md`

## 具体修复方式

不改变已验证的源码集结构，改用 `compileJava test`（编译主源码并测试）检查全部主端和客户端代码。

## 如何验证

先用 `gradlew tasks --all`（列出全部任务）确认只有 `compileJava`，再运行 `compileJava test`。

## 下次应避免

执行构建前先依据本项目实际任务列表选择任务，不再调用已确认不存在的 `compileClientJava`。
