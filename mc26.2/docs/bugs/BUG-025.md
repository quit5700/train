# BUG-025：线路设置器窗口错位与中栏无法排序

## 问题类型
客户端界面 / 输入事件问题

## 1. 问题现象
非全屏时三栏和底部控件超出窗口，设备名称显示异常；创建线路控件不在中栏内；中栏节点不能重排，道岔必须先选方向。

## 2. 根本原因
界面固定使用 600×270 坐标；`mouseReleased` 先交给父类后自定义拖动无法执行；方向按钮没有按设备类型控制；新道岔没有默认方向。

## 3. 修改文件
- `RailwayManagerScreen.java`
- `RailwaySavedData.java`
- `LineEditorModelTest.java`

## 4. 修复方式
按窗口计算布局与页容量；先处理自定义释放事件；仅选中道岔时显示方向按钮；新道岔默认直行。

## 5. 验证方式
执行相关测试和完整构建；人工检查窗口化、全屏、三栏拖动、重排和右键删除。

## 6. 下次避免
多栏界面不得依赖固定屏幕偏移；自定义拖动释放不能放在可能消费事件的父类调用之后。
