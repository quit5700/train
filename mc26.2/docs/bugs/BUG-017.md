# BUG-017：道岔误显示为探测铁轨

## 问题现象

道岔中央显示红色边框和灰色压力板，看起来像车站设备，没有十字路口的四向铁轨。

## 根本原因

道岔模型直接引用了原版 `detector_rail`（探测铁轨）纹理，且只有单条铁轨平面。

## 修改了哪些文件

- 道岔 blockstate（方块状态）和四个道岔模型
- `SwitchModelResourcesTest.java`
- BUG 记录与索引

## 具体修复方式

用两层互相旋转 90 度的普通铁轨组成四向十字道岔，移除探测/激活/动力铁轨红色纹理，增加钻石青蓝方向标记。

## 如何验证

修复前新增的两项资源回归测试稳定失败；修复后全部通过，并通过客户端资源加载检查。

## 下次应避免

不要用具有不同业务语义的原版功能铁轨纹理代替道岔专用模型。
