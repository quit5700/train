# BUG-010：测试服务器子进程仍占用世界

## 问题现象

第二次运行 `runServer`（启动服务器）时报告世界目录的一部分被其他进程锁定，日志文件也无法轮换。

## 根本原因

第一次测试中 Gradle（构建工具）任务因标准输入结束而返回，但它启动的 Minecraft 专用服务器 Java（爪哇）子进程仍在后台运行并持有世界锁。

## 修改文件

- 本 BUG 记录与索引；无模组源码修改。

## 具体修复方式

依据完整命令行精确确认本项目 `KnotServer`（Fabric 测试服务器）进程并停止；后续启动验证在看到 `Done`（启动完成）后主动停止对应子进程。

## 如何验证

确认旧进程消失，再启动服务器并检查不再出现目录锁错误。

## 下次应避免

不能只根据 Gradle 任务返回判断测试服务器已退出；必须同时检查本项目对应的 Java 子进程。
