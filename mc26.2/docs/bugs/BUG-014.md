# BUG-014：删除线路没有解绑运行列车

## 问题现象

线路设置已删除，但已加载列车仍保留旧线路编号和自动运行状态。

## 根本原因

删除网络处理只移除了线路存档，未遍历服务端已加载的关联实体。

## 修改了哪些文件

- `TrainLink.java`
- `TrainControllerManager.java`
- `LineSettingsNetworking.java`
- BUG 记录与索引

## 具体修复方式

删除前在所有服务端维度中解绑该线路的已加载车辆，关闭自动运行，清除路径进度、暂停计时和道岔锁，并注销活动列车计数。货运账本不受影响。

## 如何验证已经修好

重新编译、执行全部回归测试，并启动客户端与专用服务端。

## 下次应避免

删除持久化业务对象时，必须同时处理已加载运行实体、临时锁和活动索引。
