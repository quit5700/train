# BUG-015：线路关闭与维护状态运行行为错误

## 问题现象

线路设为“关闭”后，已运行列车跳过后续节点处理，无法正常返回车辆段；设为“维护”后，自动速度维持仍可让列车前进。

## 根本原因

节点处理将“关闭”和“维护”都当成简单返回，没有实现两种状态不同的运行语义。

## 修改了哪些文件

- `TrainControllerManager.java`
- BUG 记录与索引

## 具体修复方式

关闭线路只阻止新车发出，已运行列车继续按节点运行并在终点车辆段回收。维护模式在整列更新入口将全部车辆速度归零，保留自动状态，恢复运行后可继续。“暂停发车”仍允许现有列车运行。

## 如何验证已经修好

执行干净构建、全部回归测试和 Dedicated Server（专用服务器）启动。

## 下次应避免

不要将不同业务状态合并为一个“停止处理”分支；应分别验证发车与已运行列车的行为。
