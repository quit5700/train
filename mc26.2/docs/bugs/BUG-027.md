# BUG-027：旧版 PowerShell 批量翻译脚本不兼容

## 问题类型
中文路径 / 编码 / 构建资源问题

## 1. 问题现象
添加八种语言键时 `ConvertFrom-Json -AsHashtable` 报参数不存在，语言文件被写空。

## 2. 根本原因
当前 Windows PowerShell 不支持该参数，脚本写入前没有校验解析结果。

## 3. 修改文件
- `src/main/resources/assets/fabric_train_simulator/lang/*.json`

## 4. 修复方式
从本项目成功编译的资源副本恢复；改用 `PSCustomObject + Add-Member`，以 UTF-8 无 BOM 写入并重新解析。

## 5. 验证方式
八个 JSON 均重新解析成功，并运行翻译键集合和占位符一致性测试。

## 6. 下次避免
已尝试失败：`ConvertFrom-Json -AsHashtable`。旧版 PowerShell 不再使用该参数；覆盖前必须验证解析结果。
