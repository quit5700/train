# BUG-026：车辆段、车站容器和列车状态规则不完整

## 问题类型
数据保存 / 服务端核心逻辑 / 客户端界面问题

## 1. 问题现象
车辆段缺少线路、车型、间隔和在轨数量设置且只用内部库存；车站缺少容器状态和手动卸货；车头驻停仍会移动；编组无音效；驶离铁轨未掉落。

## 2. 根本原因
方块实体未持久化运行配置；容器服务只读取内部库存；车站数据缺少卸货字段；驻停只清零速度；脱轨仍沿用旧回收设计。

## 3. 修改文件
- `TrainDepotBlockEntity.java`、`DepotNetworking.java`、`DepotSettingsScreen.java`
- `DepotDispatchService.java`、`DepotRecoveryService.java`
- `RailwayDevice.java`、`DeviceSettingsNetworking.java`、`DeviceSettingsScreen.java`
- `CargoTransferService.java`、`TrainControllerManager.java`
- `LocomotiveEntity.java`、`TrainFormationService.java`、`DerailedTrainRecoveryService.java`

## 4. 修复方式
持久化车辆段运行设置；发车与回收覆盖相邻容器和漏斗；车站增加两态连接显示及单向手动卸货；驻停锁定坐标；增加连接音效；脱轨掉落车辆和货物。

## 5. 验证方式
执行单元测试、翻译一致性测试和完整构建；游戏内人工覆盖多容器、创造立即发车、末端回收和脱轨。

## 6. 下次避免
方块设置必须同时覆盖持久化、网络、服务端、界面和迁移；容器操作必须先模拟容量再提交。
