# BUG-072：线路保存缺少确认并停留在编辑页

- 类型：客户端与服务端同步 / 用户界面问题
- 状态：`0.2.40` 已修复代码，待游戏验收
- 影响版本：全部八个支持版本

## 问题现象

线路编辑页点击保存后没有明确反馈，也没有返回铁路线路设置器初始界面。

## 根本原因

服务端完成重命名保存后仍以当前线路编号重新打开编辑页，返回数据也没有保存成功状态。

## 修复方式

保存成功后由服务端明确返回初始页状态；客户端显示一次“已保存”。选中线路时在“线路”标题下显示“正在修改：线路名称”，并预留状态行，避免覆盖第一条线路节点。

## 验证

八个版本均执行正式 `clean build`（清理并构建），测试、普通 JAR 和 sources JAR（源码包）生成成功。仍需游戏内点击保存验收页面跳转和提示位置。

## 已尝试失败

- `compileClientJava` 不是本项目注册的 Gradle（构建工具）任务，不能作为单独客户端编译命令；最终统一使用 `clean build`，不得重复使用该错误任务名。

## 下次应避免

不得在客户端点击按钮时提前显示保存成功；必须以服务端完成数据修改后的返回为准。
