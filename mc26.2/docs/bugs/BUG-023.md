# BUG-023：物品栏显示原始翻译键

## 问题现象
部分物品名称显示为 `item.fabric_train_simulator...`。

## 根本原因
Minecraft 26.2（我的世界 26.2）的方块物品使用物品注册标识生成名称键，语言文件只提供了 `block（方块）` 键。

## 修改了哪些文件
- 八个语言 JSON 文件
- `InventoryPresentationResourcesTest.java`

## 具体修复方式
为信号铁轨、道岔、车辆段、车站和铁路发电机补齐八种语言的 `item（物品）` 键。

## 如何验证
修复前测试稳定报告缺失键；补齐后物品键测试、八语言键集合测试及 JSON 解析全部通过。

## 下次应避免
注册新方块物品时必须同时检查运行版本实际采用的 `block` 和 `item` 名称键。
