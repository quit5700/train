# BUG-062：坡道铁轨误用矿车出口坐标而被判定为线路不完整

- 类型：核心逻辑 / 线路验证 / Minecraft 26.2 原版规则适配
- 状态：`0.2.26` 已修复代码，待游戏验收

## 1. 问题现象

全部使用本模组信号铁轨铺设的“上坡→高处平轨→下坡”轨道在刷新或立即发车时被提示线路不完整。从低处向高处有时可通过，从高处向低处容易失败。

## 2. 根本原因

`WorldLineValidator（世界线路验证器）`使用 `AbstractMinecart.exits（矿车运动出口）`当作铁轨方块的相邻坐标。Minecraft 26.2 中该表是矿车运动参考坐标，与 `RailState.updateConnections（铁轨连接状态更新）`的方块坐标不同。例如东向上坡的原版连接是“西侧同高 + 东侧上方”，旧代码却把低端查到再下一格。

## 3. 修改文件

- `route/RailConnectionResolver.java`
- `route/WorldLineValidator.java`
- `route/RailConnectionResolverTest.java`
- `route/WorldLineValidatorContractTest.java`

未修改上坡、弯轨模型或纹理资源。

## 4. 修复方式

建立单一 `RailConnectionResolver（铁轨连接解析器）`，按原版 `RailState`的十种 `RailShape（铁轨形状）`返回三维连接坐标。相邻列查找顺序同原版一致：预期坐标、上方、下方。线路节点扫描和车辆段接入方向共用该解析器。

## 5. 验证

- 东、西、南、北四种上坡的坐标与原版一致。
- 四个方向各连续 10 格坡道，上坡和下坡方向都能扫描。
- 与玩家截图一致的“上坡→坡顶平轨→下坡”可双向扫描。
- `TrackPathScannerTest` 确认防车站掉头与循环线路仍正常。
- 完整 `Gradle（构建工具）` 回归共 208 项，0 失败、0 错误。

## 6. 下次避免

不得再把矿车运动出口表当作铁轨方块连接表。轨道识别、线路验证和发车接入必须共用同一原版坐标解析器。
