# BUG-016：Minecraft 26.2 方块与更新器类型适配

## 问题现象

新增车站和铁路发电机后 Java（爪哇）编译失败：`Blocks.COPPER_BLOCK` 不是单个 `Block`，发电机更新方法也无法直接作为方块实体更新器的方法引用。

## 根本原因

Minecraft 26.2（我的世界 26.2）把铜块静态字段更改为 `WeatheringCopperCollection`（风化铜集合）；`BlockEntityTicker`（方块实体更新器）的世界参数仍是通用 `Level`，而实现方法过早限定成了 `ServerLevel`。

## 修改了哪些文件

- `ModBlocks.java`
- `PowerGeneratorBlock.java`
- BUG 记录与索引

## 具体修复方式

车站的物理属性改为从单个铁块复制，外观仍由自定义铜色模型决定。更新器改为接收通用世界后在 Lambda（匿名函数）中判断并转换为服务端世界。

## 如何验证

重新执行 Java 编译、定向测试与全部回归测试。

## 下次应避免

不要假设新版 `Blocks` 中的同名字段仍是单块对象；方块实体更新器不要用参数更窄的方法引用。
