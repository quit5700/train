# BUG-005：可重新赋值的节点变量被 Lambda 捕获

## 问题现象

列车控制器编译时报“从 Lambda（匿名函数）引用的本地变量必须是最终变量或实际上的最终变量”。

## 根本原因

为了兼容车辆段位于轨道下方，`current` 节点变量存在第二次赋值；后续自动卸货流式操作又捕获了该变量。

## 修改文件

- `src/main/java/cn/quit5700/fabrictrain/train/TrainControllerManager.java`

## 修复方式

节点判空后创建不可变 `currentNode` 引用，Lambda 只捕获该引用。

## 验证方式

运行完整干净构建及所有回归测试。

## 下次应避免

需要在流式操作中使用经过回退查找的变量时，应在查找结束后先固化为不可变引用。
