# BUG-049：Minecraft 26.2 当前窗口字段不可用

## 类型

版本适配 / 客户端界面构建问题。

## 问题现象

为列车列表增加“关闭后返回车辆段设置窗口”时，`compileJava（Java 编译）`报错：`Minecraft`类中不存在可直接读取的 `screen`字段。

## 根本原因

误用了其他版本或其他命名映射下的客户端当前窗口字段。Minecraft 26.2 的 Mojang Official Mappings（Mojang 官方命名映射）只公开 `setScreenAndShow(Screen)`，没有公开的 `screen`字段或对应 getter（读取方法）。

## 修改文件

- `src/client/java/cn/quit5700/fabrictrain/FabricTrainClient.java`
- `src/client/java/cn/quit5700/fabrictrain/client/TrainListScreen.java`
- `src/test/java/cn/quit5700/fabrictrain/depot/DepotTrainListContractTest.java`

## 修复方式

删除读取不存在字段的附加返回逻辑。列车列表继续使用独立窗口，关闭按钮按 Minecraft 26.2 的标准窗口关闭行为处理。

## 已尝试失败

- `Minecraft.getInstance().screen`：Minecraft 26.2 Mojang Official Mappings（Mojang 官方命名映射）中不存在，禁止再次使用。

## 验证方式

- 使用 `javap（Java 类检查器）`检查 Minecraft 26.2 映射 JAR，确认只有 `setScreenAndShow(Screen)`而没有公开当前窗口字段。
- 重新执行干净构建和完整自动测试。

## 下次避免

需要保留父窗口时，应在发起请求前由本模组自行保存父窗口引用，不能假定 Minecraft 客户端公开当前窗口字段；任何客户端 API 名称都先以 26.2 映射 JAR 为准。
