# BUG-021：铁路线路设置器界面与需求不符

## 问题类型

需求实现偏差 / 客户端界面问题。

## 问题现象

铁路线路设置器只显示设备和线路两个翻页区域，不能清楚地看到“设备、线路、所选对象设置”三部分。

## 根本原因

实现时把设置器错误简化成了两个对象浏览器，没有保留需求中的第三个设置区域。

## 修改文件

- `src/client/java/cn/quit5700/fabrictrain/client/RailwayManagerScreen.java`

## 具体修复方式

主界面重排为三栏：左栏选择车站、道岔或车辆段；中栏选择线路；右栏显示当前设备和线路，并分别进入对应设置窗口。车辆段继续进入编组与库存设置，车站/道岔进入名称和业务设置，线路进入线路参数设置。

## 如何验证

客户端源码编译和完整自动测试通过。界面结构仍需玩家在游戏内按实际显示比例确认。

## 下次应避免

需求明确规定界面信息架构时，不得擅自压缩成更少的区域；即使底层功能存在，也不能用完全不同的交互代替。
