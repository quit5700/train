# BUG-003：列车控制器漏导入道岔锁类

## 问题现象

`TrainControllerManager`（列车控制器）编译时报找不到 `SwitchLockManager`（道岔锁管理器）。

## 根本原因

道岔锁类位于 `cn.quit5700.fabrictrain.route` 包，新增线路节点处理时遗漏显式导入。

## 修改文件

- `src/main/java/cn/quit5700/fabrictrain/train/TrainControllerManager.java`

## 修复方式

增加准确的 `SwitchLockManager` 导入，不移动类、不进行无关重构。

## 验证方式

运行完整干净构建和相关道岔锁测试。

## 下次应避免

同名领域组件跨 `train`（列车）与 `route`（线路）包调用时，完成编辑后先检查导入再构建。
