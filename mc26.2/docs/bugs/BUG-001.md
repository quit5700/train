# BUG-001：Minecraft 26.2 玩家消息方法变化

## 问题现象

编译 `DeviceBlock`（设备方块）时报错：找不到 `Player.displayClientMessage(Component, boolean)`。

## 根本原因

Minecraft 26.2（我的世界 26.2）的 Mojang Official Mappings（Mojang 官方命名映射）不再提供该方法；可用接口为 `Player.sendSystemMessage(Component)`。

## 修改文件

- `src/main/java/cn/quit5700/fabrictrain/block/DeviceBlock.java`
- `src/main/java/cn/quit5700/fabrictrain/network/DepotNetworking.java`（`0.2.25` 列车列表未选线路提示）

## 修复方式

把设备序号提示改为 `player.sendSystemMessage(...)`，玩家可见内容继续使用 Translation Key（翻译键）。

`0.2.25` 新增车辆段列表校验时再次遇到同类编译错误，已立即按本记录改用 `ServerPlayer.sendSystemMessage(...)`，没有继续尝试旧接口。

## 验证方式

运行：

```powershell
.\gradlew.bat clean build --no-daemon --console=plain
```

## 下次应避免

不要在 Minecraft 26.x（我的世界 26 系列）重复使用旧版本的 `displayClientMessage`；先通过当前映射的类签名确认消息接口。
