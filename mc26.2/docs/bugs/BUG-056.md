# BUG-056：设置器远程车辆段按钮静默失效

## 问题类型

客户端与服务端 / 权限 / 车辆段设置问题。

## 问题现象

从铁路线路设置器点击车辆段能够打开与 `Ctrl（控制键）+右键`相同的设置窗口，但保存、暂停/继续、立即生成、立即发车和列车列表可能全部无反应；靠近车辆段直接打开时正常。

## 根本原因

设置器入口没有距离限制，车辆段所有服务端按钮却分别要求玩家距离方块不超过 8 格。远程窗口提交请求后被距离判断直接返回，且没有任何拒绝提示。`0.2.22` 只修复了设置器拖动捕获，没有触及该服务端权限矛盾。

## 具体修复方式

1. 玩家使用线路设置器时创建五分钟的设置器会话。
2. 设置器选择一个车辆段时，服务端为该玩家、维度和车辆段坐标创建五分钟远程授权。
3. 保存、暂停/继续、立即生成、立即发车、列车列表与返回窗口统一调用同一权限判断。
4. 直接 `Ctrl（控制键）+右键`仍只允许 8 格内操作；没有远程授权的伪造请求不能绕过距离限制。
5. 关闭窗口、断开连接、服务器停止或会话超时会撤销授权；拒绝时显示翻译后的明确原因。

## 如何验证

1. 距离车辆段超过 8 格，用设置器进入后依次测试所有按钮，窗口应保持并显示操作结果。
2. 关闭窗口后伪造或重复发送旧请求，应显示远程权限失效且不得修改车辆段。
3. 在车辆段旁直接 `Ctrl（控制键）+右键`，全部功能保持正常。
4. 另一名玩家、另一车辆段坐标或另一维度不能复用该授权。

## 已执行验证

- 自动测试覆盖玩家、车辆段坐标、维度、超时、主动撤销和统一权限入口；完整自动回归通过。
- 真实多人服务器和设置器远距离操作仍待玩家验收。

## 下次遇到类似问题应避免什么

同一设置页有本地与远程两个入口时，必须显式保存入口授权上下文；禁止让打开窗口与提交操作使用互相矛盾的权限条件，也禁止静默丢弃失败请求。
