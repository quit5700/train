# BUG-007：全实体集合接口类型不匹配

## 问题现象

列车类别菜单编译失败：`getAllEntities()`（取得全部实体）返回的 `Iterable`（可迭代对象）没有 `stream()`（流）方法，事件中的基础 `Level`（世界）类型也没有 `getAllEntities()`。

## 根本原因

代码错误地把 Minecraft 26.2（我的世界 26.2）的服务端实体迭代接口当作 Java Collection（集合），同时未在事件中先缩窄为 `ServerLevel`（服务端世界）。

## 修改文件

- `TrainClassNetworking.java`
- `TrainInteractionEvents.java`
- 本 BUG 记录与索引

## 具体修复方式

统一通过显式 `for`（循环）遍历 `ServerLevel.getAllEntities()`，并集中到 `hasCargo`（是否含货车）辅助方法。

## 如何验证

运行 `compileJava test`（编译并测试）。

## 下次应避免

不要假设 Minecraft API（应用程序接口）返回标准集合；先查看其声明类型。服务端专用实体枚举必须先确认世界类型。
