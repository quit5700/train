# BUG-115 界面内容被背景模糊

类型：客户端渲染顺序与版本接口差异。现象：货场与车辆段标题、标签、物品图标模糊，原生输入框和按钮清晰。旧1.21.4包已在独立客户端实际复现并截图。

根因：这两个页面缺少背景方法覆盖，在自绘完成后调用Screen.render，原生renderBackground再次执行全屏模糊；后画的原生控件不受影响。1.21.1存在相同原生调用。其余自绘设置页已覆盖或不调用该原生流程，原生发电机容器先画背景再画槽位，未发现同类顺序错误。1.20.4背景只作渐变遮罩，1.20.1的render不会自动追加背景，代码核对未发现同一模糊机制，因此没有修改或重装这两版。

修改：仅在1.21.4、1.21.1的FreightYardScreen.java和DepotSettingsScreen.java覆盖晚调用的renderBackground为空，与其他设置页的现有做法一致。界面布局、字体、控件、点击、筛选、库存和所有资源不变。

验证：新增UiRenderOrderTest，旧包原逻辑测试明确失败于DepotSettingsScreen；修复后九类调用原生控件的自绘页面检查通过。1.21.4修复前后实际打开货场与车辆段截图对照；1.21.1独立环境实际打开两页确认清晰。两个版本完整检查通过。

排除：保持1.21.4窗口、字体、模组组合相同，仅改变背景覆盖后恢复清晰，排除缩放、字体或其他模组为本次直接原因。1.21.1原目录混有面向1.20.1的Porting Lib等依赖，原实例启动被其版本检查拒绝；未修改、删除或替换这些无关模组，改用同版Fabric API和本模组的独立环境验证。不能把该独立验证说成原实例已经可以正常启动。

防回归：新增自绘页面必须检查其背景方法继承来源，避免在画完内容后才调用原生模糊；必须同时看自绘文字／图标和原生控件，不能仅凭按钮清晰判定整个页面正常。旧版接口按各版核对，不把新接口复制到旧版。
