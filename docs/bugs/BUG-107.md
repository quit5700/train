# BUG-107 · 1.21.10 车辆段与线路设置崩溃

- 类型：版本适配、客户端界面生命周期。影响 0.2.42-test24，修复目标为 0.2.42-test25。
- 现象：在「测试宝箱」存档打开 (16, -61, 454) 的车辆段3，客户端首次绘制时崩溃。通过线路设置数据包打开线路编辑页也能复现。
- 根因：`DepotSettingsScreen.java` 和 `LineSettingsScreen.java` 的构造函数在界面字体初始化前创建名称输入框，输入框缓存了空字体，绘制时调用字体的截取方法触发空指针。
- 修复：构造函数保存初始名称，首次 `init()` 再用已初始化的字体创建输入框。缩放时复用输入框，保留草稿。界面布局、资源、网络协议和存档格式沿用测试24。
- 验证：真实客户端在测试24复现两页崩溃，测试25通过中文输入、窗口缩放保留草稿和重开读取已保存名称。货场实际右键打开并进入设置页，名称草稿保留、中文搜索可输入。站点、道岔和铁路管理页通过打开检查。337 项单元测试、115 项服务端保存检查、9 项重载检查全部通过。
- 防回归：参考 [BUG-106](BUG-106.md)，检查各设置页是否在构造时向输入框传递界面字体，并在真实客户端打开、输入和缩放。货场使用的是初始化后创建控件的写法。其他游戏版本未纳入本轮修复。
- 证据与复现脚本见 [BUG-107 验证目录](evidence/BUG-107/)。
