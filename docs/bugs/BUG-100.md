# 自动列车重进存档后停住

- 归类：存档恢复和运行时供电状态。
- 现象：自动车进档后能看见，线路重新发车正常，旧车停在原地。
- 根因：旧车从已保存的线路恢复时可以重建实体和行车路径，但整线供电缓存只存在于上一次运行。缓存空时供电检查拒绝运行。
- 文件：26.2、26.3 的 TrainControllerManager.java 和 PowerSectionCache.java，另有 AutomaticRestartProbe.java 实际重启专项。
- 修复：运行中的线路缺少整线缓存时，检查当前与下一格的实时供电。已有缓存继续使用原分段供电检查。恢复等待中的列车时清零逻辑速度，防止到期前滑行。
- 验证：保存途中和停站两种自动货车，重开同一存档，检查原列车编号、原编组、17个钻石、实体重新出现后的位移及剩余停站时间。断开红石接线后检查停车。
- 已排除的测试方法：只比较进档前与实体首次出现时的位置会将后台模拟位移误算成恢复行驶，故测量实体再次出现后的位移。
- 防回归：恢复持久化线路时分别检查运行时供电状态和待恢复的停车计时。不得以重新发车作为恢复验收。
