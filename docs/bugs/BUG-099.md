# 手动倒车被道岔拦停后无法前进

- 归类：列车控制状态和实体速度不同步。
- 现象：按 S 倒车到反向不通的道岔能停下，但紧接着按 W 仍停在原地。
- 根因：手动道岔拒绝时直接结束本刻，只清除实体速度。逻辑速度仍为负，每刻仍以倒车方向尝试同一道岔。
- 文件：十版的 TrainControllerManager.java、SmokeChecks.java、ManualSwitchSmoke.java。
- 改法：在手动道岔拦停分支同时停止逻辑速度。继续按 S 仍按倒车方向检查；按 W 时从静止状态按正向检查。
- 验证：26.3 修复前实际服务器通过 S 后拦停检查，在 W 驶离检查失败；修复后十版都通过 S、W、再按 S 的位置检查。完整自动检查共4583项。[分版结果](../十版手动倒车道岔修复_0.2.42-test17.md)
- 构建记录：分盘构建首次缺少 Jade（玉石）编译用测试依赖，复制原项目 test-fixtures（测试资源）到中转根后恢复。不得通过删掉兼容代码解决依赖缺失。
- 复现夹具：未连接网络的测试玩家若直接进入原版乘客更新会因连接为空崩溃。仅测试玩家覆盖此更新，仍由服务端真实挂载、检查驾驶权限和逐刻移动车头。
- 原有回归：已尝试失败的测试编排是在车站通行阶段之前跑驾驶用例，导致原本以服务器刻计时的边界清理缺少等待时间。将驾驶用例移到原有断言之后，保留旧测试的等待和预期。
- 防回归：遇到提前返回的停车分支，检查逻辑速度和实体速度是否同时归零。保持道岔固定出口和通行权判定。
