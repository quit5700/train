# BUG-103 · 26.1.2 通行设置器预览不显示

- 分类：客户端渲染 / Fabric API（应用程序接口）版本适配。
- 现象：选区通行生效，手持设置器时已保存范围、光标虚拟块和第一点至光标的预览均不可见。
- 根因：26.1.2 的预览在半透明地形绘制前才向世界渲染队列提交自定义几何，这时本帧相应几何的收集与绘制阶段已经过去。
- 修改文件：`src/client/java/cn/quit5700/stationaccess/client/RangeRenderer.java`。把三种框共用的绘制回调移至 `COLLECT_SUBMITS`（收集绘制提交）事件。保留持有检测、原版框隐藏规则、范围颜色和坐标逻辑。
- 验证：保留实例模组组合，在「测试宝箱」副本复现旧版，再以最终运行包实测。固定镜头截取手持、首点后移动光标和切走工具三帧，按颜色比对轮廓；完整自动检查 453 项通过。
- 防回归：范围数据和选点网络包正常不能证明已渲染，保留真实客户端截图对照。避免把自定义几何重新提交到地形绘制阶段，也避免用修改存档、重新保存范围或改变范围透明度来绕过。
