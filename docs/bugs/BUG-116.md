# BUG-116 1.21.4独立车头过弯偏离

类型：手动轨道几何与客户端位置插值。现象：手动物品直接放置并乘坐的车头过弯时偏离线路。测试用真实物品放车、真实乘坐并按W，四向闭合弯道连续运行；独立客车、货车也作对照，未对其增加独立驾驶功能。

根因分两层：服务器空线路游标把相邻方块中心直接连接，在弯轨处偏离原版进出边界连线约0.27～0.32格；只修此层后，客户端原版线性插值仍在不断更新的同步目标间走直线，切过弯道内侧。渲染状态实测出现posOnRail为空，排除纯粹模型朝向或原版矿车物理叠加为唯一原因。中间失败方案“仅修服务器位置”已保留证据，不得重复当成最终方案。

修改：RailSegmentGeometry.java定义平轨、四向弯轨、斜轨的真实边界线；RailMotionCursor.java仅对无固定路线的手动游标按边界线累计真实距离，支持正反移动，并保持站点居中吸附。固定自动路线advanceRoute方法逐字一致，TrainControllerManager、发车、停站、货物、回收与数据存档代码均未改动。

客户端：RailInterpolation.java按相邻同步目标追加沿轨路径，512点队列和256节点搜索均有上限，不新增网络协议。LocomotiveEntity.java仅在客户端受控车头原版位置插值时沿该路径推进；TrainVehicleRenderer.java在帧间同样按轨道取位置，再交给原版的轨道前后点与角度逻辑。不增加旋转补偿，不改变原版乘坐与碰撞规则。其他两类实体源码保持不变。

验证：四项几何测试覆盖四向弯道、中心投影、反向行驶和斜轨高度；两项插值测试验证按拐角路径而非端点弦线取位置。实际客户端用三类物品直接放车，在28.8／120.6／1000三种速度设置下记录服务器位置；单独车头连续150格以上过四向弯道，误差降至浮点误差量级。额外记录原生MinecartRenderState中的实际显示位置，修复后误差同样降至浮点误差量级。长测1200游戏刻，实际控制速度达到13.8888888889格／刻，即1000公里／时，并完成持续过弯显示检查。不是只把输入框填写1000后就声称已达到该速度。

防回归：使用原有ManualSwitchSmoke真实场景，验证S倒车到道岔前拦停、随后W可向前、再S仍受拦停规则约束。完整回归保留原预期。不得用服务器坐标正确代替客户端显示正确，也不得用模型旋转偏置掩盖路径错误。

仅1.21.4包含本项车辆修改。1.21.1只包含界面修复，不复制1.21.4新增的RenderState接口。模型、材质、物品标识、配方和语言资源全部逐字一致。
