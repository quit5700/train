# BUG-082：通行范围占据方块位置并产生黑影和原版选中框

当前项目根：Fabric模拟火车模组。分类：范围逻辑与世界数据／客户端渲染。

用户要求范围为纯逻辑、可正常放置方块；旧实现BoundaryWork在空心外壳实际放置透明BOUNDARY方块。RenderShape.INVISIBLE只隐藏模型，不等同空气，不保证透光、可替换或没有选中框。截图表现为空中范围下方黑影、光标处原版方块黑框。

修复前复现：26.3/test2先只加入真实世界“logical_surface_never_occupies_world”检查，沿用test1生产实现，独立临时世界明确失败。原始失败JSON与日志位于evidence/BUG-082。未修改用户存档。

拟定修复：不再创建边界方块；服务端以坐标穿越判断执行车票权限；普通方块放置和破坏不受区域拦截；仅遗留边界ID在已加载区块分批清理，不创建新区块或清理其他模组方块。客户端手持工具时隐藏原版选中框并始终显示白色光标虚拟框，区域只作线框渲染。创造模式持设置器潜行左键移除单格逻辑边界。

涉及文件：十版BoundaryWork、BoundaryBlock、StationAccess、AccessService、AccessNetwork、AccessData、RangeController、RangeRenderer、SmokeChecks及翻译。

验证状态：修复前实际失败已确认；修复后的分版本检查与验证证据稍后补充。不得把未运行的检查写成修复成功。

已尝试失败：用INVISIBLE隐藏模型并noOcclusion代替纯逻辑边界；实体边界继续存在会产生占位与光照问题。不得通过只调材质或仅隐藏原版黑框掩盖本质占位。

26.3接口适配：ChunkPos坐标为私有记录字段，采用稳定的getMinBlockX/Z访问器；Properties无碰撞方法在26系列已更名，遗留方块已有getCollisionShape空形状重写，因此不引入多余的跨版属性方法，仅标记可替换。首次编译失败日志保留在本BUG证据内；禁止继续使用直接x/z字段或统一拼写noCollission跨全版本。

26.3验证时序：在同一服务端tick放石头后立刻移除，canSeeSky仍受异步光照队列影响；1.20.1/1.21.10的同项检查已通过。将光照检查移动到后续tick，至多等待140tick，透光预期不变、不跳过失败，另检查更多tick后仍为空气，防止再生实体边界。

阶段结果：26.3服务器66项功能检查及6项真实保存重载通过；独立临时客户端的holding_setter、cursor_target_air、boundary_cell_air、boundary_can_see_sky均为true，截图可见白色光标立方框且地面无整块范围阴影。客户端自动正常退出，未打开用户存档。其余九版正执行最终检查。

最终验证：十版全部完成单元与真实服务器检查，合计3640项；每版66项功能与6项保存重载，源码指纹与运行包资源核对一致。没有删除收费、所有权、建造及原列车的正确预期。安装与交接记录见本次合并版验收汇总及安装记录。剩余风险：其他九版客户端实际鼠标操作没有逐版实机验收，不能以26.3实机代表全部版本。

客户端输入收口：仅“创造＋持设置器＋潜行左键”发送逻辑缺口请求，普通创意攻击与普通拆方块不截获。增加CursorActions生产决策及5项真值组合回归。调整前完整报告和服务端源码/字节码指纹已保留；仅改客户端输入后重跑全部单元及构建，严格比较服务端源码与编译结果不变才沿用本轮66+6项世界检查，若变化则重新启动完整服务器验证。原候选运行包和源码另存候选历史，不覆盖。
