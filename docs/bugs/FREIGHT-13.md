# 货运装货段与车辆段卸货设置

类型：新增货运功能、列车与库存状态保存、旧版和新版客户端接口适配。

## 实现与回归边界

- 线路节点新增货运装货段，保存最早加入顺序。只让当前匹配线路的自动货车在车头到达正上方时停靠。首个节点是货场时，从节点零开始处理，普通旧线路继续使用原来的起始节点规则。
- 车厢分类和库存用货车厢顺序号索引，和具体车辆实体分离。减少编组时保留规则并退货。重复匹配按件轮流分配，箱子中的退货数量设为保留量，避免被货场反复吸入。跨区块的装货库存与虚拟列车共同写入基础设施存档。
- 车辆段编组旧格式只有车型字符，新格式在原编组后追加各车卸货站。旧字段可以直接读取。生成的车头和车厢各自保存站点。卸货时用实际库存或上次区块卸载前的容量快照，已安排的待交付货物会占用预留空间。
- 模型、配方和八语言资源跨版复用。确认外观见设计目录。客户端菜单沿用原生按钮和滑块，物品图标渲染在分色背景上。第三方临时保管箱按注册方块标识和容器接口识别。

## 适配中遇到的问题

- 1.20.1和1.20.4未提供新版矿车当前位置接口，复用本项目旧版矿车兼容层。早期直接调用新版方法失败。
- 界面加载接口由Fabric原生界面模块提供。各版构建分别使用安装目标对应的模块版本。26系列使用组件集合接口，其余版本使用按钮集合接口。尝试对所有版本直接调用旧按钮接口已失败。
- 旧绘制对象没有新版外框方法。边框统一用四条原生填充绘制。
- 原帮助注册检查固定预期13个物品和边界说明。新物品加入后检查总数增加一项，重复注册及缺少可选模组的保护断言保留。

验证覆盖编组格式迁移、隐藏页规则持久化、线路顺序、退货防循环及独立服务器保存重载。真实货运专项从车辆段保存入口发车，经自然卸载后装货，再按车辆段配置卸货，重载后检查实际收货箱。

最终结果：4557项检查通过。[分版结果](../十版货运装货段与卸货设置_0.2.42-test13.md)。
