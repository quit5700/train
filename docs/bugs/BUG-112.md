# 三款方块外观更新

0.2.42-test35，仅更换已确认的三款模型、材质和共用模型生成的物品栏图标。车票充值器为现代地铁充值机，外观一格占地、两格高；发电机为一格微缩发电厂；车辆段以白色为主、蓝色为辅，顶面平整，继续承载铁轨。十个版本共用同一套31张材质与6份模型资源，不重新设计各版外观。

明确保留：全部Java源码和编译类与test34逐字节一致；方块与物品标识、注册、放置、碰撞、操作、界面、配方、掉落、供电、燃料、存档及列车逻辑均未修改。模型在旧存档中自动替换，不需要重新放置。

充值器操作仍点击下半部；上半部是模型延伸，上方需要留空。本轮没有把它改成上下两个逻辑方块，也没有增加两格碰撞。发电厂的视觉空隙仍沿用原方块碰撞，符合仅改模型的授权范围。

验证：十版各自构建并运行原有完整回归；逐个核对运行包和源码包中的37项资源、PNG格式、贴图引用、六个面的完整性及模型边界。逐字节核对全部Java源文件及运行包编译类未变，其他资源也未发生变更。1.21.8和26.3实际进入独立测试宝箱副本，确认三款模型、对应库存图标、两格外观和车辆段顶面信号铁轨；每版7项场景检查及原生截图已保存，无缺失模型／纹理警告。其他八版未逐个进行玩家手工外观验收。

已尝试失败与处理：首次自定义几何改用block/block父模型，触发原有基础设施六面资源契约测试。最终继续采用block/cube父模型及原有六面材质路径，用elements定义新造型，所有六面资源实际用于模型，保留旧测试原预期后通过。没有删改或跳过测试。26.3独立截图工具使用旧版时间和天气设置接口无法编译，按实际游戏类核对后改用时钟管理器和WeatherData；只改测试工具，运行包代码不变。测试编译器和脚本明确使用UTF-8，避免中文错误输出乱码。

后续防回归：模型改造前应检查当前资源契约；不要用更换功能代码的方式处理外观问题。保留37项共享资源清单和三个确认图的对应关系。两格外观不能自动视作两格碰撞或新增交互授权。

本次为测试版，未上传发行版。每版Minecraft、Java、Fabric Loader、Fabric API、Fabric Loom和命名映射信息见该版本的VERSION_INFO.txt。原测试交付保留。
