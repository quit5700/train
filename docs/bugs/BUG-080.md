# BUG-080：离线测试布局的跨版本存档格式

项目根：Fabric模拟火车模组。分类：数据读取／版本适配；只记录本项目放置工具的实际问题。

现象：规划26系列测试宝箱时，旧版region位置找不到主世界；26.3调色板读取假定全是Name字段复合对象时失败。所有异常发生在只读规划阶段，未写用户存档。

根因：26系列主世界移至dimensions/minecraft/overworld/region；26.3 DataVersion5023允许字符串调色板和空键包装，带属性对象使用id及properties。部分小存档只有中心48×64已完整生成，大布局放不下。

涉及文件：tools/world_test_layout.py、tools/test_world_test_layout.py；未修改用户游戏生成规则。

修复方式：只选择唯一有数据的主世界目录；调色板统一读取，26.3按原生格式写回；先尝试完整布局，再选择保持相同拓扑的紧凑布局。仅编辑已完整生成区块；逐区块NBT字节无损往返；全空草地检查；持有会话锁；原子落盘，核对失败从内存回滚。遵照用户要求不备份存档。

已尝试失败：固定world/region、假定Name/Properties统一结构、只用大布局覆盖所有小图。不得无证据继续采用。

验证：合成中文目录10项自动检查通过，覆盖调色板位宽和有符号长整数、中文NBT无损往返、修改区域外方块保留、其他区块原始字节保留、26.3字符串调色板迁移、坡向/弯道/整体旋转、中文路径原子替换、缺运行包拒绝修改、失败回滚及占用地块拒绝。实际用户世界放置结果另见docs/测试宝箱_线路放置结果.json；没有结果前不得声称已放好。

后续避免：不得启动只带本模组的开发服载入用户混合模组世界；不得生成未完成地形区块或覆盖既有设施；不得以能读NBT代替无损校验。

实际执行补充：第一次追加方块实体时发现原生空block_entities列表的元素类型为End，nbtlib拒绝直接追加Compound。异常发生于内存预处理阶段，尚未调用写入事务，未写任何用户区域文件。修复为空列表先显式设为Compound列表，并加入native_empty_end_list_accepts_first_block_entity回归；10项全部通过后才执行正式放置。十版存档均放置并落盘读回核对成功，位置与结果见相邻交付记录。禁止以后假定空NBT列表已经有复合元素类型。
