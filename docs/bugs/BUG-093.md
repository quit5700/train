# BUG-093：十版生成诊断、占位与尾轨不足

项目根目录：本Git仓库。初次只读调查未修改运行代码；随后获授权的test10处理和最终验证见末节。用户本次授权查看正在运行的26.3，不退出、不换包、不编辑存档。

现象：用户先报告无供电，再报告首次生成成功、第二次失败；客货、手动自动均有失败。截图的确切提示为“编组位置没有连续的信号铁轨，或空间被阻挡”，不能直接归类为整条线路断轨或车型限制。

2026-11-05正在运行的26.3日志确认fabric_train_simulator为0.2.42-test9，快捷建筑为1.1.9-test18。游戏窗口可见原起点附近仍停着列车。只读最近保存数据确认车辆段2位于(64,-61,52)，模板PPPP，最后自动生成结果ordinal=6，对应TRACK_SPACE_INVALID。47号手动列车属于该车辆段，车头(64.5,-59.5,52.5)，4节客车Z坐标51.25、50、48.75、47.5，仍占原生成区域。新列车会在相同坐标生成，空间检查拒绝是预期保护，不应删除碰撞检查或归因为货车型号。

同一只读地形中，北向预留轨道止于Z=47，Z=46及更北为空气。生成5节车厢时，第5节中心Z=52.5-5*1.25=46.25，其所在方块Z=46缺轨；4节时最后一节Z=47.5有轨。截图曾显示5节货车，但目前保存模板为4节客车，不能把不同节数结果当作纯车型对照。

发电机(67,-60,46)保存库存有1红石块且有燃料预留记录；这排除了“库存必定没有燃料”的解释，尚不能据此证明报错瞬间供电缓存正确。供电误报仍需原始失败条件或独立实际引擎重现，不能把本次空间问题当成供电问题已经修好。

当前代码在DepotDispatchService.java同一条件中合并“实体所在格不是信号轨/道岔”和“level.noCollision为false”两种失败。推荐后续拆分原因，显示具体第几节车、坐标与阻挡类别，生成前提供所需尾轨长度提示。先以当前停着的整列车驶离生成区、以及相同节数客货对照验证，不取消正确的空间约束。

调查限制：磁盘数据是运行中最近保存快照，内存状态可能继续变化；日志未写每节车辆的失败明细。未执行发车、删除、传送或方块修改，不以静态检查声称已经修复。电脑操作只查看游戏；键盘命令栏未可靠打开，未输入诊断命令。日志由启动器指定GB18030编码，需按该编码以FileShare.ReadWrite共享读取，直接ReadAllText可能被写入句柄拒绝；不得用UTF-8乱码日志作为原始中文提示证据。

防重复：报错必须先核对确切翻译键；记录模板节数、方向、每节坐标及既有车辆，不把相同混合提示统一当断轨。继续修复前先用上述现场条件建立回归，再修改最小范围。

## test10授权与处理

用户随后明确授权处理，并保存退出26.3。十版追加缺轨、实体占位、实体方块阻挡、区块未加载四类结果；结果附车头/车厢序号和坐标，通过既有可变参数网络传输，保持界面布局。只在枚举末尾追加新值，旧存档TRACK_SPACE_INVALID=6与SPAWN_FAILED=7不变。生成保护保留，失败不产生部分编组、不扣车辆物品。按钮悬停显示建议尾轨长度，测试宝箱出发段北侧补8格连续信号轨，既有车、库存和线路不变。供电独立复现见BUG-094。

尾轨预检发现部分紧凑布局跨入未生成区块，初版安全检查按设计拒绝。后续复用对应版本已验证原生生成的平坦区块，不伪造NBT（命名二进制标签）结构，不覆盖已有设施。此为预检发现的地图条件，非运行逻辑缺陷。

诊断条件修正：旧版在同一刻刚加载生成测试区、立即创建列车后，实体尚未进入世界查询索引，原版与新增查询都可能看不到它。后续改为在场景初始化时提前加载该区，等待至700刻再生成；旧版仅在临时世界保留起点和测试区的临时更新票据，结束前撤销。经校正，1.21.4旧test9也能拒绝已有列车占位，不能把初版诊断的重叠结果当作已证实生产缺陷。test10保留显式车辆/可交互实体包围盒检查，统一生成前安全条件；不宣称原版各旧版必然无法防重叠。

跨版本诊断编译失败：ChunkPos在26.3为记录类型，x/z字段私有，旧版公开字段写法不可共用。已统一从BlockPos使用右移4位取得区块坐标，未更改生产代码映射。

修改文件清单（十版分别适配）：depot/DepotDispatchResult.java、depot/DepotDispatchService.java、network/DepotNetworking.java、client/DepotSettingsScreen.java、八种assets/fabric_train_simulator/lang语言资源及SpawnFailureDetailsTest.java。生成诊断走既有网络可变参数通道，不重做界面；明确车辆包围盒检查保留原阻挡保护。
