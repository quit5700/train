# BUG-106 · 1.21.10 设备设置页打开时退出

- 分类：客户端设置页生命周期和版本接口差异。
- 现象：模拟火车 test19 收到「站点1」的打开设备设置数据包后，文本框首次绘制抛出空指针。旧包在「测试宝箱」副本复现同一堆栈。
- 根因：1.21.10 的 Screen（页面）在初始化时提供字体。设备设置页构造器提前把空字体传给两个 EditBox（输入框）。
- 修改文件：`src/client/java/cn/quit5700/fabrictrain/client/DeviceSettingsScreen.java`。构造时保留初始文字，首次初始化时创建输入框。调整大小或重排组件时复用原控件，保存与布局沿用原逻辑。
- 验证：真实客户端用原模组组合打开站点和道岔设置，输入中文并调整真实窗口大小，核对未保存草稿与后续输入。完整自动检查另见交付说明。
- 防回归：升级界面接口时核对字体初始化时机；覆盖实际绘制和窗口重排，避免只测构造函数或重建时覆盖草稿。没有尝试通过移除其他模组绕过问题。
