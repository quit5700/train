# BUG-078：通行设置器外观与确认图不一致

当前项目根：Fabric模拟火车模组。分类：模型／外观。用户明确反馈整体造型、边框和手柄不像。

原因：旧独立包的实际设置器只有4个大立方体，只有正面简化贴图，未实现已确认图的强化金属边框、蓝色侧板、后盖螺钉、分段手柄与底托；GUI投影角还易展示背面。跨版复制资源一致只能证明同一模型复用，不能证明符合确认图。

文件：10版assets/station_access/models/item/setter.json。保留setter_before.json证据与原确认图design/approved/通行设置器.png。

修正：按确认图用原生JSON立方体构建完整框体、独立蓝色显示面、金属角护、黄按钮与状态灯、后盖和分段手柄，继续使用原PNG材质，不另换设计；补齐左右手显示并调整物品栏朝向。模型与材质可原生实现，10版统一复用同一JSON。

验证：JSON、面UV与10版摘要检查；实际模型源码渲染预览供核对。最终手持与物品栏比例仍需游戏实测，不把原稿与运行材质有对应关系等同外观已通过。

预防：以后必须核对实际原生模型渲染的预览，不能只提供设计图再用简化模型交付。
