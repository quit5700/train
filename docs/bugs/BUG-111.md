# 十版发电机燃料限制与提示

本轮仅修改发电机：只允许红石粉和红石块进入，普通放入、快捷移入、数字键交换、拖拽及遵循容器接口的自动输入使用相同规则。历史存档里的其他物品仍可取出。保留原有9格箱子布局、燃料燃烧时间、供电、存档和其他功能。

打开界面后，物品栏上方常驻显示“燃料：仅限红石粉、红石块”。空槽显示淡色红石粉图标；悬停说明供电用途。尝试放入其他物品时拒绝并短暂显示提示。中英等八种语言均使用翻译键。

根本原因：方块实体已经覆盖容器 canPlaceItem（是否可放入），但普通 ChestMenu（箱子菜单）的 Slot（槽位）默认允许所有物品，未接入该检查。快捷移动合并历史非燃料堆叠还需独立拦截。

修改文件：PowerGeneratorBlockEntity.java、GeneratorFuelSlots.java、GeneratorScreen.java、FabricTrainClient.java、GeneratorFuelSlotsTest.java、八种语言文件。源码差异按允许清单逐个核对，其他源文件与 test33 完全相同；未新增混入钩子或改燃料结算逻辑。

验证：旧 test33 实际打开菜单，第一格允许非燃料，拒绝规则断言失败。test34 在1.21.8及26.3独立测试宝箱副本中，分别完成25项服务端与客户端检查，包括真实菜单库存、九槽限制、手动放入、快捷移动、数字键交换、漏斗同一传输入口、两种有效燃料、旧非燃料取出、界面同步、错误提示和实际截图。十版各运行新增4项槽位回归及完整原有检查。并非十版都已人工操作验收。

已尝试失败：26.3仅调用游戏基础初始化不足以创建测试物品堆栈，报“组件尚未绑定”；测试环境补充原生注册表及数据组件初始化。26.1.2、26.2使用createLookup（创建查找），26.3使用createWorldLookup（创建世界查找），已分别核对，不能直接复制方法名。26系列最初采用物品绘制加遮罩，实机截图发现淡色图标未显示，改为同一原版红石粉纹理的透明绘制，重新构建并截图通过。交付校验还发现1.20.1的源码归档未包含最后一次等价的燃料判定委托修改，已重新构建并核对源文件与归档逐字一致。不关闭测试或弱化正确预期绕过这些问题。下次新增物品测试应核对目标版本初始化流程，界面必须看实际截图，所有代码编辑完成后再构建最终包。

防回归：新增测试验证两种燃料允许、非燃料及其他红石元件拒绝、历史非燃料安全取出、槽位坐标及编号不变。旧燃料时长、供电及燃料预留测试全部保留。外部模组若绕过容器接口强行改写内部数据，不属于标准自动输入接口。

本次为0.2.42-test34测试版，不上传发行版。运行包安装到已核实的十版本、十一实例；源码包仅归档，不放入游戏模组目录。用户此前对26.2和26.3的正常反馈属于test33，不能当作本轮玩家验收。

中文环境核验：安装脚本最初控制台按系统代码页输出中文路径，工具读取时显示乱码，但实际UTF-8安装记录和路径正确；已将交付、安装与最终核验脚本的标准输出明确设为UTF-8，并重新显示、核对十一处中文目录及SHA-256校验值。以后避免依赖Python控制台默认编码。
