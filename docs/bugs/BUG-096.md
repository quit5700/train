# BUG-096 车辆段保存发车与站点停靠记录

类型：车辆段状态、停站计时、列车列表与存档数据。

- 现象：保存车辆段配置只写设置，原按钮名称无法说明其回收行为。配置页面重复显示上一次自动发车结果。列车列表没有到站历史，停站时与车辆互动还会把当前停靠倒计时重设为通用互动延时。
- 原因：保存分支直接返回，立即发车与重置共用原按钮。列车登记未存储到站事件，实体和离线运行各自处理站点。停站和互动暂停共用同一种计时状态。
- 修复：保存后用已保存配置尝试立即发出一列自动列车，检查实际在轨上限和发车条件。只有重置会在成功发车后回收同线路旧自动列车，上限为零时保留原有回收分支。自动停靠只从车站读取时间，特快使用客车停靠时间。分别在实体和离线到站处记录站名，进入列车登记的可选存档字段。
- 文件：十版的车辆段网络处理、车辆段设置页、列车列表页、列车登记、实体列车控制与离线运行服务、八种语言资源及相关回归测试。
- 防复发：用保存数据回归检查站名顺序、重复经过和回收清理。真实服务器测试保存发车、达到上限时保留旧车、自然卸载到站及重载。禁止把线路的计划节点直接作为实际到站记录，或以测试手工创建的离线状态替代自然卸载。
- 已尝试失败：初轮构建的四项断言仍写死了旧保存分支、旧重置守卫和旧列表负载的源码文本。更新与本次行为变化直接对应的断言，继续检查原有删除边界和列表请求。

最终验证：十版共4773项通过，包含每版32项真实服务器专项。[分版结果](../十版保存发车与到站记录_0.2.42-test12.md)。
