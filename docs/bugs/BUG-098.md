# BUG-098 货场搜索框与临时保管箱箱群供货

类型：分类界面、可选联动、跨方块库存访问。

- 现象：上一版整理下拉菜单时移除了搜索框。普通箱子能给货场供货，连接成箱群的临时保管箱有货时可能不供货。
- 复现：用当前 26.3 实际安装的万能宝箱 1.01-test20 运行包，单箱与贴着货场的箱群成员能供货。货放在连通但未直接贴着货场的成员时，旧版复现零转移。断开的箱子保持原库存。
- 根因：货场只访问六面相邻容器。万能宝箱界面合并显示整个箱群，每个临时箱方块实体各自保存 20 格。货场读到了相邻箱本身的空库存。
- 修复：仅对注册标识为万能宝箱临时保管箱的容器沿六面遍历已加载成员，多个入口去重。转移和退回继续使用实际成员的库存及坐标。搜索框复用原生文本组件，同时按类别、当前车厢已有选择和搜索词筛选。
- 文件：十版 FreightYardService（货场服务）、FreightYardScreen（货场界面），以及临时箱真实运行和客户端搜索探针。
- 验证：临时箱单箱、邻接成员、连通远端、断开箱及普通箱对照。26.3 中文客户端验证搜索结果与已有物品取交集。各版本独立构建、服务器保存与重载。
- 防止复发：可选联动应使用实际第三方运行包与真实箱群验证。调整下拉菜单数量时，应将文本搜索组件纳入交互回归。

另行观察自动运行顿挫。两次现场性能记录分别得到 1,100 个和 17 个服务端执行样本。第一次有 1,056 个进入万能宝箱调度，其中 572 个进入目标容量计算，火车模组出现在 7 个样本中。第二次未采到该分类循环。用户确认顿挫没有再出现，本轮保留观察，未改动万能宝箱代码和游戏存档。

最终结果：共4517项通过。[分版结果](../十版货场搜索与临时箱修复_0.2.42-test15.md)。
