# BUG-079：独立服务器错误要求客户端渲染模块

分类：客户端／服务端依赖。当前项目根为Fabric模拟火车模组。

现象：1.20.1与1.20.4完整单元检查通过，专用服务器因depends要求fabric-rendering-v1和fabric-blockrenderlayer-v1而被加载器拒绝。实际API归档存在，但这些旧版子模块的environment为client，服务端正常排除它们。

根因：合并依赖扫描只核对类所在模块，没有区分环境；不能把客户端专用渲染模块作为通用模组的服务端硬依赖。

修改：对应版本fabric.mod.json和build.gradle。将客户端专用子模块移到suggests，1.20／1.21统一硬依赖本机实际完整Fabric API，开发服务器通过modRuntimeOnly加载总包；26系列保留已验证的真实通用子模块方案，不引入全量编译包。

已尝试失败：对客户端专用渲染模块声明通用depends。不能用禁用服务端检查或让服务端强装客户端类绕过。

验证：逐版本重新加载专用服务器，并验证13物品同页、真实车辆与权限墙、保存重载。最终结果见各版本报告。
