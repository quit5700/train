# 26.3 登录后卡在轨道区块边界

- 归类：区块自然加载时序和运行时供电缓存。
- 现象：从原登录点进入「测试宝箱」时，前车停在 Z=127.7，Z=128 已可更新但供电查询持续为否，后车等前车让位。
- 根因：首次供电遍历经过尚不可读取的区块边界时，轨道被跳过；区块之后可读取但发电机状态未变化，供电缓存没有重算。
- 文件：26.3 RailPowerService.java。记录实际供电路径遇到的不可读取区块，每五刻被动检查一次。发现其中任一变为可读取时沿用合并重算。停止服务器时清空边界记录。
- 验证：同一真实单人登录点对照旧包和新包。两列九节编组自动通过区块边界且不重叠。完整回归 456 项，另通过真实断电和单列停站测试。
- 已排除的测试方法：预先强制加载前方区块无法复现首次供电遍历遗漏。临时实例首次漏带 Fabric API，补齐原版依赖后通过真实客户端复现。禁止把该弹窗当作正式实例依赖故障。
- 防回归：既要验证区块会按玩家位置分批加载，也要验证供电计算发生在区块可被动读取后。不要强制加载或跳过实际供电检查。
