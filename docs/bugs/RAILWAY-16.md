# 车票复用与线路列表

- 归类：购买规则、客户端列表布局和点击边界。
- 原因：充值目标原先只检查双手。列表容量原先使用全部行高，节点点击也未受可见行数约束。两侧行文字只绘制自定义名称和编号。
- 文件：各版的 Transactions.java、AccessNetwork.java、RailwayManagerScreen.java、SmokeChecks.java，以及两个资源命名空间的八种语言文件。
- 改法：购买和充值界面共用车票槽位优先级。设备类型从枚举查翻译键。三栏共用扣除一行后的容量，节点点击也按该容量限制。
- 验证：十版完整自动回归验证钱包、扣款和发票位置，26.3 中文客户端覆盖刚满时滚动、底部空行和节点编辑。共4533项通过。分版结果见[交付说明](../十版车票复用与线路列表_0.2.42-test16.md)。
- 防回归：发新票和充值必须共用一套槽位规则。渲染、滚动和点击要共用可见容量。不能只为列表留绘制间距。
