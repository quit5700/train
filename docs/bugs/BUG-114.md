# 1.21.4发电机空槽提示虚化

范围：仅Minecraft（我的世界）1.21.4，0.2.42-test37测试版。只修改GeneratorScreen.java的空槽绘制三行，不更改其他九版。

类型：客户端界面渲染层级／透明度。现象：没有放入燃料的提示红石粉显示为实色，易与真实燃料混淆。原因：原先先画物品，再加灰色矩形遮罩；1.21.4中物品的深度与遮罩不同，遮罩未覆盖物品。此现象已在旧包独立客户端截图复现。

修复：沿用原先“槽位有物品就continue”的判断；空槽直接绘制同一原版红石粉纹理，逐顶点颜色透明度为0x66，即40%。实际放入的物品仍由原版容器绘制，不使用该透明度；不使用影响整页的全局颜色状态。交互、提示文字、布局、燃料、供电、库存、模型、材质、配方和存档逻辑全部保持原样。

验证：1.21.4完整345项自动检查通过；旧包和新包各实际进入测试宝箱的独立副本，25项容器／燃料检查通过，并截取实际界面。对照三个真实燃料槽的整个32×32像素区域，修复前后逐像素一致；六个空槽区域颜色强度为原先约40.48%，确认虚化生效。全部资源及除GeneratorScreen外的编译类均与test36逐字节一致。未修改用户存档。

已尝试失败方案：旧的“实色物品＋灰色遮罩”在本版本无效，后续不要重新使用。防回归：空槽提示要检查渲染层级并截取真实游戏画面；透明度应仅作用于提示纹理，不能改变实际燃料的颜色或渲染状态。截图像素比较脚本和前后原图均已保留。

安装：只替换已核实的1.21.4-Fabric游戏目录运行包，源码包保存在交付目录，不放入模组目录。其他版本运行包的校验值在安装前后核对保持一致。仍为测试版，不发布正式发行版。用户明确要求完成后一次性关机，须在安装与最终校验完成后再安排。
