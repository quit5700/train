模拟火车 0.2.41 正式版

本次发布 Minecraft（我的世界）1.20.1 和 1.20.4 两个版本。其他支持版本继续使用 0.2.40。

修复列车轨迹累计超过 140 格后清理循环无法结束、导致服务器方块交互和指令无响应的问题。原代码对双端队列按整数对象删除，未真正移除旧轨迹点；现在正确删除队尾。轨迹采样、车厢间距、模型、道岔交互、界面和存档格式保持原有行为。

本版由用户明确确认的 0.2.41-test1 转为正式版本号，运行功能没有新增修改。1.20.1 的 244 项测试及 1.20.4 的 242 项测试均通过，没有跳过测试；包含超过实际轨迹上限、反复清理、大跨度移动、反向路径和跟随插值的防回归检查。1.20.1 测试版用户实机反馈正常；1.20.4 实机反馈仍待完成。

两版均提供运行 JAR（Java归档）和 sources JAR（源码归档）。下载与游戏版本完全一致的运行包，停止客户端或服务器后替换旧运行包，勿同时安装两个相同模组的运行包。源码包不安装到 mods（模组）目录。旧正式版和测试版的软件及源码继续保留。

依赖：Java（爪哇）17、Fabric Loader（Fabric模组加载器）0.15.11、Fabric Loom（Fabric构建插件）1.6.12。Fabric API（Fabric应用程序接口）分别为 0.92.9+1.20.1 和 0.97.3+1.20.4。Yarn Mappings（Yarn命名映射）未使用，采用对应游戏版本的 Mojang Official Mappings（Mojang官方命名映射）。
