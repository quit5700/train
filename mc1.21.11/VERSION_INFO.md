0.2.40：铁路线路设置器选中线路时显示“正在修改：线路名称”；服务端确认保存成功后返回初始页面并显示“已保存”。

0.2.39 在立即发车校验前统一补齐旧道岔记录的入口方向，避免第一次误报断轨、查看道岔后第二次才能发车。铁路线路设置器在选中线路时于标题下显示“正在修改：线路名称”。SavedData（全局存档数据）中的设备与线路登记是正常存档的权威来源；仅设备和线路均为空的旧存档才扫描区块恢复。既有数据格式、车辆运动和模型未修改。`0.2.39-diagnostic.1` 的临时持久化日志已全部移除。本地构建同时生成普通 JAR 和 sources JAR（源码 Java 归档）。

0.2.38 修复铁路线路设置器的服务端管理授权可能失效后静默丢弃创建、拖动和保存请求的问题。服务端每次打开或刷新设置器时更新授权；玩家仍手持线路设置器时允许恢复刚失效的授权。线路存档结构与其他功能不变。

0.2.37 增加旧世界区块设备自动恢复：先按 NBT（命名二进制标签）中实际设备/线路数量选择有效 SavedData（全局存档数据），再从 Anvil Region（区域存档）找出包含车站、道岔、车辆段的候选区块，每游戏刻最多恢复一个区块。较新的空存档不会覆盖有效备份；有效存档保存 .recovery.bak。只补齐缺失坐标，不修改健康存档已有编号、名称、设置和线路。磁盘路径不使用冒号，兼容中文、空格和 Windows 路径。
