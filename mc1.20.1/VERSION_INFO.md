0.2.40：铁路线路设置器选中线路时显示“正在修改：线路名称”；服务端确认保存成功后返回初始页面并显示“已保存”。

当前版本移除全局设备交互回调中遗留的车站、道岔普通右键开窗路径，确保两者只有 `Ctrl（控制键）+右键`打开设置；车辆段普通右键库存不变，设置仍使用 `Ctrl（控制键）+右键`。铁路线路设置器的三列独立滚动和进入游戏提示保持不变。列车运行、编组、模型和既有数据格式未修改。本地构建同时生成普通 JAR 和 sources JAR（源码 Java 归档）。

0.2.37 增加旧世界区块设备自动恢复：先按 NBT（命名二进制标签）中实际设备/线路数量选择有效 SavedData（全局存档数据），再从 Anvil Region（区域存档）找出包含车站、道岔、车辆段的候选区块，每游戏刻最多恢复一个区块。较新的空存档不会覆盖有效备份；有效存档保存 .recovery.bak。只补齐缺失坐标，不修改健康存档已有编号、名称、设置和线路。磁盘路径不使用冒号，兼容中文、空格和 Windows 路径。
